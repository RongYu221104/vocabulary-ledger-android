# Font provenance

English uses the system Georgia face, then Times New Roman / serif. No Georgia font binary is redistributed.

Chinese uses unmodified Source Han Serif SC Regular (Adobe official release), under SIL OFL 1.1. The complete license is OFL.txt. Source URL: https://raw.githubusercontent.com/adobe-fonts/source-han-serif/release/OTF/SimplifiedChinese/SourceHanSerifSC-Regular.otf

No Anthropic font is used or included in the cloud source.
