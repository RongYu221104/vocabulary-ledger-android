# 官方词汇账本来源

词形依据2016年修订版考试大纲词表。释义、译文和原创例句为项目编辑内容。真题例句采用经过逐词审核的短句。

来源简称中的套号采用来源PDF封面编号；部分出版渠道对同一内容使用不同套号，别名完整保留在每条记录的 provenance.sourceEvidence.setAliases 中，不声称存在统一的官方套序认证。PDF页码、SHA-256、题型和来源链接见同一元数据字段。听力选项不等同于听力原声转录。

完整研究证据、原始Markdown与新旧对照保留在项目独立审计数据目录，不在卡片上展示。原始八字段保留于 provenance.fields；少数代词的译文补明另有标记。
