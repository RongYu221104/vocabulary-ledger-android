# Vocabulary Ledger · 词汇账本

整理英语词汇，记录学习进度，让背诵和复习更有条理。

## 📥 [下载 Android 安装包 · v1.3.0](https://github.com/RongYu221104/vocabulary-ledger-android/releases/download/v1.3.0/vocabulary-ledger-android-1.3.0.apk)

**🌐 [打开网页版](https://vocabulary-ledger.rongyu1104.chatgpt.site/)**

## 主要功能

- **四六级词库**：内置完整四级、六级词汇账本，支持搜索、筛选、预览和整本复制。
- **个人词汇账本**：创建账本与子账本，自由编辑单词、释义、双语例句和备注。
- **智能复习**：按遗忘曲线安排复习，记录“忘记 / 记得”和掌握状态。
- **学习统计**：查看今日进度、近 30 天趋势和学习记录，自定义每日新词量与统计重置时间。
- **离线与备份**：Android 版无需联网，数据保存在本机，支持 JSON 导入导出；网页版支持登录和云端保存。
