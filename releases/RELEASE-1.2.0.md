## 安装、升级和离线使用

下载本 Release 的正式 APK 与 SHA256SUMS.txt，校验 SHA-256 后安装。包名为 `site.chatgpt.rongyu1104.cetledger`，正式证书 SHA-256 为 `06682961dead953cbbae7afdd30b6859c12f256be9456a0a0183e482eae79a87`。系统允许安装的授权由设备所有者完成。

同一正式证书的版本可覆盖安装，升级前建议导出 JSON。旧 Debug 测试包与本正式证书不同，不能直接覆盖；如有旧数据，应先导出备份，再由用户自行处理旧包。本项目的测试和发布脚本不会卸载应用或清除数据。

在 HarmonyOS 7.0 上，可通过用户已安装的卓易通安装 APK。系统 Download 目录在容器选择器中可能显示为“我的设备(鸿蒙)/Download”。文件流程以实际设备为准。应用没有 INTERNET 权限，词库不依赖运行时访问网站；容器自身的网络行为不在本应用权限声明的范围内。
