# Android 1.3.0 安装、升级与离线使用

1. 从本项目正式 GitHub Release 下载 `vocabulary-ledger-android-1.3.0.apk` 和 `SHA256SUMS.txt`，核验 SHA-256：`5c306867523fe7c1ac9dd0e3ac8f099982ff5e04647aa8a611bedcacf947d441`。
2. 升级前在旧版导出 JSON，在应用或卓易通容器外另存一份。不要卸载旧版、清除应用数据或清除卓易通容器数据。
3. 正式 1.2.0 与 1.3.0 同包名、同证书，可选择系统的覆盖更新流程。旧 Debug 签名不兼容，不能用卸载清数据“修复”升级。
4. 鸿蒙 7.0 通过用户已安装的卓易通处理 APK；不假定手机可用标准 ADB。用户在设备上自行批准安装。宿主 Download 文件夹在容器内可能显示为“我的设备(鸿蒙)/Download”，以系统文件选择器为准。
5. 打开后先核对原有账本、词条、复习历史和 UTC 设置；退出重开后再次核对。应用保留既有文件、SQLite、IndexedDB 和 JSON 标识，没有清库迁移。
6. 新版官方内容从顶部“官方词汇账本”进入；可浏览、搜索、按首字母和分页查看，并复制为独立个人账本。同形词合并保留全部释义/例句；官方原本只读。已有个人副本不会被升级自动重写。
7. 断网时仍可使用全部本机功能。没有 ChatGPT 登录或云同步，其他设备通过 JSON 手动迁移；容器自己的联网行为不等于应用申请了 INTERNET 权限。
8. JSON 导出应在系统选择保存位置后确认实际文件可访问。导入前核对预览：“合并”保留现有数据并添加副本，“覆盖”替换全部数据。重要原始备份不要只放在应用内自动备份中。

本轮没有对鸿蒙实体设备执行新版覆盖与系统文件选择器验收；这是待验证范围，不将旧版通过记录当成本版证明。如果遇到升级、保存或文件选择器问题，保留原安装和备份，记录版本、文件大小、错误提示及操作步骤，避免反复导入或卸载。
